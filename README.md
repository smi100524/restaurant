# 赛尔美餐厅 SMISS Restaurant · 点餐系统

「一席烟火气，万般皆如意；诚邀品鉴，共赴食光。」

一套纯前端、可直接部署到 GitHub Pages 的餐厅点餐系统，宋式美学风格（宣纸底、汝窑天青、印章红、鎏金点缀）。

## 页面说明

| 文件 | 页面 | 说明 |
| --- | --- | --- |
| `index.html` | 首页 | 餐厅介绍 + 预订（客户可访问） |
| `menu.html` | 点菜页 | 浏览菜单、加菜、确认预订（客户可访问） |
| `admin.html` | 管理端 | 菜单/品类管理、批量导入、数据管理、邮件设置（需密码登录） |

## 功能

- **首页**：宋式排版，预订表单（客户 / 电话 / 预订部门 / 预订人 / 日期时间 / 人数 / 备注），提交后先核对信息，确认后进入点菜页
- **点菜页**：分类筛选、搜索、中英文双语菜名、方形菜品图、一键加菜；「确认预订」弹窗可同时修改预订信息和菜单，确认后保存订单并可导出 CSV 明细
- **管理端**（默认密码 `admin123`，登录后请在「系统设置」中修改）：
  - 品类管理：新增 / 改名 / 删除
  - 菜品管理：增删改、行内直接传图、批量导入 CSV（支持直接导入图片文件）
  - 数据管理：预订记录 / 订单记录，搜索、按日期筛选、查看订单明细、导出 CSV、删除 / 清空
  - 邮件通知：有新的预订 / 订单时自动发邮件（需配置 EmailJS）
  - 数据维护：导出 / 导入备份、恢复默认菜单

## 部署到 GitHub Pages

1. 把本项目推送到 GitHub 仓库
2. 在仓库 **Settings → Pages** 中，将 Source 设为 `main` 分支根目录（`/root`），保存
3. 访问 `https://<你的用户名>.github.io/<仓库名>/` 即可打开首页

## 本地使用

直接双击 `index.html` 即可在浏览器中使用（数据保存在本机浏览器里，请定期在管理端「数据维护」中导出备份）。

## 邮件通知配置（可选）

1. 免费注册 [EmailJS](https://www.emailjs.com)，添加邮箱服务并新建邮件模板
2. 在管理端「邮件通知设置」填入 Service ID / Template ID / Public Key 和收件邮箱，保存后点「发送测试邮件」验证
3. 邮件模板可用变量：`{{to_email}}` `{{subject}}` `{{message}}` `{{customer}}` `{{phone}}` `{{dept}}` `{{booker}}` `{{date}}` `{{time}}` `{{people}}` `{{note}}` `{{no}}` `{{items}}` `{{total}}`

## 技术说明

- 纯 HTML / CSS / JavaScript，无构建步骤、无第三方框架
- 数据存储：菜单、预订、订单存于 **Supabase 云数据库**（免费版），购物车与管理密码存于浏览器本地
- 首次使用：在 Supabase 的 SQL Editor 运行 supabase-setup.sql 建表，页面会自动填充默认菜单
- 邮件发送：EmailJS REST API（客户端直接调用）
- 菜品图片：支持上传内嵌（data URL）或引用 `images/` 文件夹中的图片
